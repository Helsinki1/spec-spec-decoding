# Working preferences

- When writing, reviewing, or refactoring code, read and apply [karpathy-guidelines](.agents/skills/karpathy-guidelines/SKILL.md). Keep code simple and readable, avoid speculative features and unnecessary abstractions, and keep changes focused on the request.
- When explaining concepts, read and apply [explain-simply](.agents/skills/explain-simply/SKILL.md). Start with the gist, use a concrete example, and explain what happens step by step and why. Use plain language, preserve the real mechanism, and introduce technical terms after the intuition.

Skill sources and pinned revisions are recorded in [.agents/skills/SOURCES.md](.agents/skills/SOURCES.md).
